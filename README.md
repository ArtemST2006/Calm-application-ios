# Calm iOS

Репозиторий разделён на `ios/` и `backend/`. В `ios/` находится Xcode-проект с четырьмя экранами онбординга по [исходному макету Figma](https://www.figma.com/design/usEux42QHb0Li3YjE2aGHo/UX-%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D1%8B?node-id=945-16574).

## Запуск на Mac

1. Откройте `ios/CalmOnboarding.xcodeproj` в Xcode.
2. Выберите схему `CalmOnboarding` и iPhone Simulator либо подключённый iPhone.
3. Для запуска на физическом устройстве выберите свою команду в **Signing & Capabilities** и при необходимости измените Bundle Identifier.
4. Нажмите **Run**.

Минимальная версия — iOS 17. На первом запуске открыт первый экран. Можно листать экраны свайпом или нажатием на точки. Кнопки «Создать аккаунт» и «Войти» открывают соответствующие формы; кнопка «Назад» возвращает в онбординг.

## Текущие ограничения

- Авторизация через сервер пока не подключена. Отправка формы показывает уведомление, не создавая аккаунт.
- Макет использует `TT Commons Classic Trl Md`. Пакет в `/home/artem/Загрузки/TT-Commons-Trial-2-200` содержит именно этот шрифт, но его Trial-лицензия не разрешает встраивание в мобильное приложение. Поэтому в iOS-проекте пока используется системный шрифт. Для точного совпадения нужен файл шрифта с лицензией на мобильное приложение; после его добавления потребуется указать его PostScript-имя в `OnboardingFont` и зарегистрировать в Xcode-проекте.
- Сборка на Linux недоступна; проект нужно проверить в Xcode на Mac.
