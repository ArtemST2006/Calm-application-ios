# Calm iOS

Репозиторий разделён на `ios/` и `backend/`. В `ios/` находится Xcode-проект с четырьмя экранами онбординга по [макету Figma](https://www.figma.com/design/H2BteWZE0LEotIa9N2Ww8P/Untitled?node-id=2-121).

## Запуск на Mac

1. Откройте `ios/CalmOnboarding.xcodeproj` в Xcode.
2. Выберите схему `CalmOnboarding` и iPhone Simulator либо подключённый iPhone.
3. Для запуска на физическом устройстве выберите свою команду в **Signing & Capabilities** и при необходимости измените Bundle Identifier.
4. Нажмите **Run**.

Минимальная версия — iOS 17. На первом запуске открыт первый экран. Можно листать экраны свайпом или нажатием на точки. Кнопки «Создать аккаунт» и «Войти» открывают соответствующие формы; кнопка «Назад» возвращает в онбординг.

## Текущие ограничения

- Авторизация через сервер пока не подключена. Отправка формы показывает уведомление, не создавая аккаунт.
- Макет использует TT Commons Classic. Доступный в рабочей среде Trial-файл не включён в репозиторий, так как его условия не разрешают встраивать шрифт в мобильное приложение. Пока используется системный шрифт iOS. После получения лицензированного файла его можно добавить в проект; код уже поддерживает имя `TTCommonsClassicTrl-Md`.
- Сборка на Linux недоступна; проект нужно проверить в Xcode на Mac.
